# README

This repository contains the code used in the manuscript *“Plasma Sphingolipid Remodeling and Branched Chain Amino acid Dysregulation as Metabolic Hallmarks of COVID-19 Severity and Long COVID .”*

The code is organized according to the main figures in the manuscript. Each script includes annotations indicating which analyses and plots correspond to individual figure panels.

## Main Figures

The code used to generate the figures is organized by related main figure sections:

- **Figure 1**: Study design
- **Figure 2**: `IMPACC_deep_dive_Figure2.Rmd`
- **Figure 3**: `IMPACC_deep_dive_Figure3.Rmd`
- **Figure 4**: `IMPACC_deep_dive_Figure4.Rmd`
- **Figure 5**: `IMPACC_deep_dive_Figure5.Rmd`
- **Figure 6**: `IMPACC_deep_dive_Figure6.Rmd`

## Notes

Please note that file paths and patient/sample identifiers used in the scripts were originally configured for execution on the IMPACC internal computing environment. These will need to be adapted for use with the publicly deposited datasets.
