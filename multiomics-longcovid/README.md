# Identification of a multi-omics factor predictive of long COVID in the IMPACC study

## Data availability

Data used in this study is available at ImmPort Shared Data under the accession number SDY1760 and in the NLM's 769 Database of Genotypes and Phenotypes (dbGaP) under the accession number phs002686.v2.p2. Note this is a controlled database with approval from NIAID required (please follow the instructions as you try to access the data). However, ImmPort has agreed to provide special access to reviewers of this article upon request by the IMPACC team.
