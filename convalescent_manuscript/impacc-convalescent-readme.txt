This is a readme document for file ‘impacc-convalescent.csv’.  This file has 5 columns:1) participant_id.  Numeric identifier which is unique to each study participant.  Format is 0XX-YZZZ where X=site identifier (01-15), Y=site location (for sites which recruit participants across multiple locations), ZZZ=three digit sequential identifier (001-199).  Healthy controls use format CX where X takes values 6-10.2) conv_cluster3.  Indicates cluster membership from the 3-cluster model.  Values:
	1 = no deficit;
	2 = uncertain deficit;
	3 = deficit.3) conv_cluster6.  Indicates cluster membership from the 6-cluster model.  Values:
	1 = no deficit (sub-cluster 1);
	2 = no deficit (sub-cluster 2);
	3 = no deficit (sub-cluster 3);
	4 = no deficit (sub-cluster 4);
	5 = deficit (sub-cluster 5);
	6 = deficit (sub-cluster 6).4) conv_physical_deficit.  Indicates deficit on the physical domain PROs.  Values:
	0 = no deficit;
	1 = deficit.
5) conv_cognitive_deficit.  Indicates deficit on the cognitive domain PROs.  Values:
	0 = no deficit;
	1 = deficit;	NA = data unavailable.
6) conv_global_deficit.  Indicates deficit on the global (non-specific health status) PROs.  Values:
	0 = no deficit;
	1 = deficit;	NA = data unavailable.
