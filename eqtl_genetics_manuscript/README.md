# Severity-stratified, longitudinal cis-eQTL mapping identifies candidate causal genes for critical COVID-19

Analysis code for the IMPACC critical COVID-19 host-genetics study (Chen et al.),
using peripheral blood mononuclear cell (PBMC) transcriptomes and host genotypes
from the IMPACC hospitalized COVID-19 cohort.

The code is organized into two self-contained analysis tracks, one per analysis in
the manuscript. Each track runs the full pipeline end to end: genotype
processing, expression processing, cis-eQTL mapping (MatrixEQTL), multiple-testing
correction (eigenMT), and Bayesian colocalization (coloc.abf) against the GenOMICC
critical COVID-19 GWAS, followed by the notebooks that generate the manuscript
figures. Run the steps within each track in numbered order. The `.Rmd` notebooks
are the analysis steps and the `.sh` scripts hold the PLINK and eigenMT commands
that run in the shell. Before running a notebook, set the input and output
locations in its "Paths and parameters" chunk.

## Data availability

The IMPACC genotype data are available through the NLM Database of Genotypes and
Phenotypes (dbGaP) under accession phs002686.v3.p2. PBMC RNA-seq counts and the
clinical and trajectory-group annotations are available through the ImmPort
database under accession SDY1760. Both are controlled-access databases requiring
NIAID approval; please follow the instructions provided when requesting access.
The GenOMICC critical COVID-19 GWAS summary statistics used for colocalization are
publicly available at https://genomicc.org/data. The 69 published critical
COVID-19 GWAS lead SNPs are drawn from the COVID-19 Host Genetics Initiative
(PMID 37674002) and GenOMICC (PMID 37198478).

## Code

### `01-hospital-admission-eqtls`  (unstratified, Visit 1)  ->  Figure 2

| Data analysis task | Path | Description | Figures |
|---|---|---|---|
| Extract GWAS loci | 00-extract_gwas_loci.sh | PLINK extraction of the +/- 1 Mb windows around the 58 critical COVID-19 lead SNPs | |
| Cohort and genotype extraction | 01-genotype_processing.Rmd | Define the analysis cohort, convert genotypes from GDS to PLINK, and extract the GWAS locus windows | |
| Expression processing | 02-expression_processing.Rmd | PBMC RNA-seq filtering, inverse-normal transform, outlier removal, and expression PCs (Buja-Eyuboglu) | |
| Genotype covariates and mapping | 03-cis_eqtl_mapping.Rmd | Build the MatrixEQTL inputs (genotype matrix, PC-AiR genotype PCs, demographic and expression covariates, order-checked) and run cis-eQTL mapping at Visit 1 | |
| eigenMT correction | 04-eigenmt_correction.Rmd (+ 04-run_eigenmt.sh) | Reformat for eigenMT, run it per chromosome (shell), combine, and compute eigenMT-corrected significance | |
| Colocalization | 05-colocalization.Rmd | coloc.abf against the GenOMICC critical COVID-19 GWAS | |
| Figure 2 | 06-figure2_hospital_admission.Rmd | Visit-1 SNP-by-gene effect-size heatmap and SNP and gene attrition bars | Figure 2A, 2B |
