# Code for IMmunoPhenotyping Assessment in a COVID-19 Cohort (IMPACC) study #

The purpose of this repository is to provide code used in the following publications from the IMPACC study.

### IMPACC manuscripts
- Clinical manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/clinical_manuscript/)
- Core assay manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/core_assay_manuscript/)
- Data integration manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/data_integration_manuscript/)
- Convalescent manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/convalescent_manuscript/)
- Aging manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/aging_manuscript/)
- Solid organ transplant manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/solid_organ_transplant_manuscript/)
- Molecular subtyping manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/molecular_subtyping/)
- Chronic viruses manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/chronic_viruses_manuscript/)
-Longitudinal multi-omics long COVID manuscript: (https://bitbucket.org/kleinstein/impacc-public-code/src/master/multiomics-longcovid/)

The files include code for data pre-processing, data analysis and output generation (individual figure panels and tables). Please see the manuscript-specific README files for instructions for set up, data download, running the code and contact information.
