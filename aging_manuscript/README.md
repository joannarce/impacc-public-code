# README #

This repository contains the code used in the paper **Host-Microbe Multiomic Profiling Reveals Age-Dependent Immune Dysregulation Associated With COVID-19 Immunopathology**.

The code is organized by main figures. The plot used to create each figure panel is annotated in the code.

The code used to produce the supplementary figures is also arranged by the related main figures:
* Fig S1, S2: ./Figure1/nasal_viralload.Rmd
* Fig S3: ./Figure1/serum_rbd_antibody.Rmd
* Fig S4: ./Figure2/blood_cytof.Rmd
* Fig S5: ./Figure3/pbmc_rnaseq.Rmd and ./Figure5/src/nasal_rnaseq.Rmd
* Fig S6: ./Figure3/pbmc_rnaseq_public_data.R
* Fig S7: ./Figure3/pbmc_rnaseq.Rmd
* Fig S8: ./Figure4/serum_olink.Rmd
* Fig S9: ./Figure5/src/Figure6.Rmd
* Fig S10: ./Figure3/pbmc_rnaseq.Rmd and ./Figure4/serum_olink.Rmd
* Fig S11: Cytoscape analysis
* Fig S12: ./Figure2/blood_cytof.Rmd

Please note that the paths and patient IDs used in the code were intended for use with the data on IMPACC's own internal server. Therefore, they will need to be changed for the deposited data.
